# Currency flag SVGs

Square (`1x1`) country flags vendored locally for wallet balance cards.

- **Fiat flags:** [lipis/flag-icons](https://github.com/lipis/flag-icons) v7.5.0 (MIT), `flags/1x1` aspect ratio
- **USDT:** project custom icon (`usdt.svg`)
- **Refresh:** `node scripts/download-currency-flags.mjs`

Currency → ISO country code mapping lives in `src/lib/money/currency-flag-codes.ts`.
